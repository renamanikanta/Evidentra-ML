# Thanmmay AI Lab

A responsive, portfolio-style AI/ML web application for Thanmmay Yanamadala, with interactive educational demos.

## What's included

- Editorial dark-mode portfolio, responsive layout, custom animated neural-network canvas.
- **Claim-denial risk demonstration:** a real `HistGradientBoostingClassifier` fit on 18,000 *synthetically generated* examples with a held-out evaluation split. Predicts a simulated risk probability from adjustable claim inputs. Input-level flags are heuristic explanations, **not** feature-importance attributions.
- **Retrieval demonstration:** locally curated mini-knowledge-base, TF-IDF bigram retrieval, cosine similarity, extractive answers, document excerpts, and explicit abstention for weak retrieval. **Not** a live LLM or generative RAG.
- **Monitoring demonstration:** seeded simulation of baseline and shifted feature distributions, PSI, paired histograms, heuristic shift indicators.
- Project highlights, research, education, and contact link, based on the supplied professional profile.

## Run locally

Requires Python 3.10+.

```bash
cd thanmmay-ai-lab
python -m venv .venv
# macOS / Linux:
source .venv/bin/activate
# Windows PowerShell:
# .venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Open **http://127.0.0.1:8000**. Interactive API docs: **http://127.0.0.1:8000/docs**.

Run tests:
```bash
pytest -q
```

## Deploy on Render

1. Push the folder's contents to GitHub.
2. Create a **New Web Service**, choose Python runtime.
3. Build command: `pip install -r requirements.txt`
4. Start command: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
5. Deploy and use the Render public URL.

Model training occurs on first call to `/api/model` or `/api/predict`; the model is cached within each worker. Render instance requirements depend on available RAM and build environment.

## Responsible-demo notes

- All inference and monitoring data are simulated and **must not** be used to make clinical, insurance, payment, or personal decisions.
- No PHI, claim history, or user prompts are stored by this app.
- Reported career metrics reflect user-supplied profile descriptions; they are not generated by the demo, independently audited, or intended as demo performance claims.
- There are no API secrets or paid model integrations.
- The portfolio demonstrates working backend ML, retrieval, and monitoring; it does **not** claim to recreate Thanmmay's proprietary employer systems or production datasets.

## Visual design
The portfolio uses an accessible, restrained light theme: warm porcelain (#F7F8F6), slate ink (#23313D), muted forest teal (#286B63), and soft blue (#496D91). The neutral-dominant palette prioritizes legibility, visual hierarchy, and recruiter-friendly presentation instead of neon lighting.
